# Настройка базы данных PostgreSQL

## Какой скрипт использовать?

### Для pgAdmin4 (Windows пользователи)

Используйте **два отдельных скрипта** в следующем порядке:

1. **`setup_windows_db_step1_create_db.sql`**
   - Подключитесь к базе `postgres` или `PostgreSQL 16`
   - Откройте Query Tool
   - Запустите этот скрипт
   - Создаст базу данных `fastener_shop`

2. **`setup_windows_db_step2_schema.sql`**
   - Подключитесь к базе `fastener_shop`
   - Откройте Query Tool
   - Запустите этот скрипт
   - Создаст таблицы и добавит тестовые данные

### Для psql (командная строка)

Используйте **один скрипт**:

```bash
psql -U postgres -f setup_windows_db.sql
```

Этот скрипт содержит команду `\c` для автоматического переключения между базами данных.

## Почему два разных подхода?

- **pgAdmin** не поддерживает psql мета-команды (такие как `\c`)
- **psql** поддерживает эти команды и может выполнить всё в одном скрипте

## Проблема: "syntax error at or near \"

Эта ошибка возникает при попытке запустить `setup_windows_db.sql` в pgAdmin.

**Решение:** Используйте скрипты `step1` и `step2` вместо единого скрипта.

## Структура базы данных

После успешной установки база данных `fastener_shop` будет содержать:

- **users** - пользователи системы
- **products** - каталог товаров (10 тестовых позиций)
- **orders** - заказы пользователей
- **order_items** - позиции в заказах

## Тестовые данные

- **Пользователь:** login: `test`, password: `test123`
- **Товары:** 10 крепежных изделий (болты, гайки, саморезы и т.д.)
