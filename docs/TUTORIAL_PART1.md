# 📚 Подробная инструкция по созданию приложения "Магазин крепежа" - ЧАСТЬ 1

## 🎯 Для кого эта инструкция?

Эта инструкция написана простым языком, чтобы любой человек (даже если ты никогда не программировал) смог создать мобильное приложение. Я буду объяснять каждый шаг подробно, как хороший учитель.

---

## 🤔 Что мы будем создавать?

Представь, что ты хочешь открыть магазин в интернете, где продаются болты, гвозди и другие штуки для ремонта. Для этого нужно:

1. **Мобильное приложение** (для телефона) - это то, что видит покупатель
2. **Сервер** (программа на компьютере) - это "мозг", который хранит информацию о товарах
3. **База данных** (как Excel таблица) - это место, где хранятся все данные

**Аналогия**: Представь ресторан:
- Мобильное приложение = Меню, которое видит посетитель
- Сервер = Официант, который принимает заказ
- База данных = Кухня, где хранятся продукты

## 🔧 ЧАСТЬ 1: Установка программ

### 1.1 Установка PostgreSQL (База данных)

**Что это?** PostgreSQL - это программа для хранения данных (как умная таблица Excel).

#### Для Windows:

1. **Скачай PostgreSQL**:
   - Открой браузер
   - Перейди на сайт: https://www.postgresql.org/download/windows/
   - Нажми "Download the installer"
   - Скачай версию для Windows (последнюю версию)

2. **Установи PostgreSQL**:
   - Запусти скачанный файл (двойной клик)
   - Нажимай "Next" (Далее)
   - Когда спросят пароль для пользователя "postgres", придумай простой пароль (например: `postgres`)
   - **ВАЖНО!** Запиши этот пароль на бумажке! Он понадобится позже
   - Порт оставь 5432 (по умолчанию)
   - Дожидайся окончания установки

3. **Проверь, что установилось**:
   - Открой "Пуск" → найди "pgAdmin 4"
   - Запусти pgAdmin 4
   - Если программа открылась - всё работает! ✅

#### Для macOS:

```bash
# Открой Терминал (Приложения → Утилиты → Терминал)
# Установи Homebrew (если ещё не установлен)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Установи PostgreSQL
brew install postgresql@15

# Запусти PostgreSQL
brew services start postgresql@15
```

#### Для Linux (Ubuntu):

```bash
# Открой Терминал (Ctrl + Alt + T)
sudo apt update
sudo apt install postgresql postgresql-contrib
sudo systemctl start postgresql
sudo systemctl enable postgresql
```

### 1.2 Установка Python (Для сервера)

**Что это?** Python - это язык программирования, на котором мы напишем сервер.

#### Для Windows:

1. Перейди на https://www.python.org/downloads/
2. Скачай последнюю версию Python (например, Python 3.12)
3. Запусти установщик
4. **ВАЖНО!** Поставь галочку "Add Python to PATH" внизу окна
5. Нажми "Install Now"

Проверка:
```
# Открой командную строку (Win + R → введи cmd → Enter)
python --version
# Должно показать: Python 3.12.x
```

#### Для macOS / Linux:

Python обычно уже установлен. Проверь:
```bash
python3 --version
```

Если нет, установи:
```bash
# macOS
brew install python3

# Linux
sudo apt install python3 python3-pip
```

## 🗄️ ЧАСТЬ 3: Создание базы данных

### 3.1 Что такое база данных простыми словами?

База данных - это как большая таблица в Excel, где хранятся данные:

| ID | Название товара | Цена | Количество |
|----|----------------|------|------------|
| 1  | Анкер 10x100   | 45.50| 150        |
| 2  | Болт М8x40     | 12.30| 500        |

Но база данных умнее Excel - она может быстро искать данные, защищать их от потери, и работать с миллионами строк.

---

### 3.2 Создаём файл схемы базы данных

**Что делаем?** Создаём файл, который скажет базе данных, какие таблицы создать.

**Шаг 1**: Открой любой текстовый редактор:
- Windows: Блокнот (Notepad++) - скачай с https://notepad-plus-plus.org/
- macOS: TextEdit или Visual Studio Code
- Linux: gedit или Visual Studio Code

**Шаг 2**: Создай новый файл и скопируй в него следующий код:

```sql
-- Это схема базы данных для магазина крепежа
-- Строки, начинающиеся с --, это комментарии (как пометки на полях в тетради)

-- Удаляем старые таблицы, если они есть (чтобы начать с чистого листа)
DROP TABLE IF EXISTS order_items CASCADE;
DROP TABLE IF EXISTS orders CASCADE;
DROP TABLE IF EXISTS products CASCADE;
DROP TABLE IF EXISTS users CASCADE;

-- Создаём таблицу пользователей (кто регистрируется в приложении)
CREATE TABLE users (
    id SERIAL PRIMARY KEY,              -- Номер пользователя (автоматически увеличивается)
    login VARCHAR(255) NOT NULL UNIQUE, -- Логин (должен быть уникальным)
    password_hash VARCHAR(255) NOT NULL,-- Зашифрованный пароль
    created_at TIMESTAMP DEFAULT NOW()  -- Когда зарегистрировался
);

-- Создаём таблицу товаров
CREATE TABLE products (
    id SERIAL PRIMARY KEY,              -- Номер товара
    name VARCHAR(255) NOT NULL,         -- Название (например, "Анкер 10x100")
    price NUMERIC(10,2) NOT NULL CHECK (price >= 0), -- Цена (не может быть отрицательной)
    stock_qty INTEGER NOT NULL DEFAULT 0 CHECK (stock_qty >= 0), -- Сколько штук на складе
    image_key VARCHAR(100),             -- Ключ для картинки
    created_at TIMESTAMP DEFAULT NOW()  -- Когда добавили товар
);

-- Создаём таблицу заказов
CREATE TABLE orders (
    id SERIAL PRIMARY KEY,              -- Номер заказа
    user_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE, -- Кто заказал
    created_at TIMESTAMP DEFAULT NOW(), -- Когда заказал
    total NUMERIC(10,2) NOT NULL CHECK (total >= 0) -- Общая сумма заказа
);

-- Создаём таблицу позиций в заказе (что именно заказали)
CREATE TABLE order_items (
    id SERIAL PRIMARY KEY,              -- Номер позиции
    order_id INTEGER NOT NULL REFERENCES orders(id) ON DELETE CASCADE, -- Номер заказа
    product_id INTEGER NOT NULL REFERENCES products(id) ON DELETE RESTRICT, -- Какой товар
    qty INTEGER NOT NULL CHECK (qty > 0), -- Сколько штук
    price_at_purchase NUMERIC(10,2) NOT NULL CHECK (price_at_purchase >= 0) -- Цена на момент покупки
);

-- Создаём индексы (чтобы база данных быстро искала)
CREATE INDEX idx_users_login ON users(login);
CREATE INDEX idx_orders_user_id ON orders(user_id);
CREATE INDEX idx_order_items_order_id ON order_items(order_id);
CREATE INDEX idx_order_items_product_id ON order_items(product_id);
```

**Шаг 3**: Сохрани этот файл:
- Файл → Сохранить как
- Перейди в папку `FastenerShop/database`
- Имя файла: `schema.sql`
- Нажми "Сохранить"

**Что мы сделали?** Создали "чертёж" для базы данных - как архитектор рисует план дома перед строительством.

---

### 3.3 Создаём начальные данные

**Что делаем?** Добавляем в базу данных первые товары, чтобы было что показать в приложении.

**Шаг 1**: Создай новый файл в текстовом редакторе

**Шаг 2**: Скопируй этот код:

```sql
-- Это начальные данные для магазина
-- Мы добавим 3 товара, чтобы было что показать в приложении

-- Добавляем товары
INSERT INTO products (name, price, stock_qty, image_key) VALUES
('Анкер 10x100 мм', 45.50, 150, 'anker_10x100'),
('Болт М8x40 оцинкованный', 12.30, 500, 'bolt_m8x40'),
('Саморез 4x16 мм', 2.50, 1000, 'samorez_4x16');

-- Проверяем, что товары добавились
SELECT * FROM products;
```

**Шаг 3**: Сохрани файл:
- Файл → Сохранить как
- Папка: `FastenerShop/database`
- Имя: `seed_data.sql`
- Сохранить

**Простыми словами**: Мы создали файл с первыми товарами для магазина. Когда мы запустим этот файл, в базе данных появятся 3 товара.
