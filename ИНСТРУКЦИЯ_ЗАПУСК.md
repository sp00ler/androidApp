# Инструкция по запуску приложения "Магазин крепежа"

## ⚠️ ВАЖНО! Обязательное условие

Папка с проектом **ОБЯЗАТЕЛЬНО** должна находиться по адресу:
```
C:\FastenerShop
```

Если у вас другой путь - переместите всю папку туда. Иначе ничего не заработает!

---

## Что нужно установить перед началом

### 1. Python (версия 3.8 или выше)
- Скачайте с официального сайта: https://www.python.org/downloads/
- При установке **обязательно** поставьте галочку "Add Python to PATH"
- После установки проверьте в командной строке:
  ```
  python --version
  ```
  Или если не работает:
  ```
  py --version
  ```

### 2. PostgreSQL (версия 12 или выше)
- Скачайте с официального сайта: https://www.postgresql.org/download/windows/
- При установке запомните пароль от пользователя `postgres` - он понадобится!

### 3. Android Studio
- Скачайте с официального сайта: https://developer.android.com/studio
- Установите со всеми стандартными компонентами

---

## Пошаговая настройка

### Шаг 1: Настройка базы данных

1. Откройте **pgAdmin 4** (установился вместе с PostgreSQL)

2. Подключитесь к серверу (введите пароль, который указывали при установке)

3. Создайте новую базу данных:
   - Правой кнопкой на **Databases** → **Create** → **Database**
   - Name: `fastener_shop_db`
   - Encoding: `UTF8`
   - Нажмите **Save**

4. Откройте **Query Tool** для новой базы:
   - Правой кнопкой на `fastener_shop_db` → **Query Tool**

5. Скопируйте весь код из файла `C:\FastenerShop\database\schema.sql` и выполните его (кнопка ▶️ Execute)

6. Добавьте тестовые товары:
   - Откройте файл `C:\FastenerShop\database\seed_data.sql`
   - Скопируйте содержимое и выполните в Query Tool

### Шаг 2: Установка Python библиотек

1. Откройте **Командную строку** (Win+R → `cmd` → Enter)

2. Перейдите в папку с сервером:
   ```
   cd C:\FastenerShop\server
   ```

3. Установите необходимые библиотеки (попробуйте оба варианта):

   **Вариант 1:**
   ```
   py -m pip install flask flask-cors psycopg2-binary werkzeug
   ```

   **Вариант 2** (если первый не работает):
   ```
   python -m pip install flask flask-cors psycopg2-binary werkzeug
   ```

   Подождите, пока все установится (может занять 1-2 минуты)

### Шаг 3: Настройка пароля базы данных (если нужно)

**Если при установке PostgreSQL вы указали пароль `postgres`** - пропустите этот шаг, всё уже настроено!

**Если указали другой пароль:**

1. Откройте файл `C:\FastenerShop\server\config.py` в любом текстовом редакторе (Блокнот подойдет)

2. Найдите строку:
   ```python
   DB_PASSWORD = os.getenv('DB_PASSWORD', 'postgres')
   ```

3. Замените `'postgres'` на ваш реальный пароль, например:
   ```python
   DB_PASSWORD = os.getenv('DB_PASSWORD', 'мой_пароль_123')
   ```

4. Сохраните файл

## Запуск проекта

### Часть 1: Запуск сервера

1. Откройте **новое окно** Командной строки (не закрывайте старое!)

2. Перейдите в папку с сервером:
   ```
   cd C:\FastenerShop\server
   ```

3. Запустите сервер одним из способов:

   **Способ 1:**
   ```
   py app.py
   ```

   **Способ 2:**
   ```
   python app.py
   ```

4. Если всё нормально, увидите:
   ```
   ====================================================
   🏪  Сервер магазина крепежа
   ====================================================
   📡  Сервер запускается на http://0.0.0.0:5000
   📋  Доступные endpoints:
       GET  /health         - Проверка работы сервера
       GET  /products       - Список товаров
       POST /auth/register  - Регистрация
       POST /auth/login     - Вход
       POST /orders         - Создание заказа

   ⚠️  Для остановки нажми Ctrl+C
   ```

5. **НЕ ЗАКРЫВАЙТЕ ЭТО ОКНО!** Сервер должен работать постоянно, пока тестируете приложение.

### Часть 2: Запуск Android приложения

#### Открытие проекта в Android Studio

1. Запустите **Android Studio**

2. На стартовом экране выберите **Open**

3. Найдите и выберите папку:
   ```
   C:\FastenerShop\android
   ```
   **Важно!** Открывайте именно папку `android`, а не всю папку `FastenerShop`!

4. Нажмите **OK**

5. Подождите, пока Android Studio загрузит проект и синхронизирует Gradle (это может занять 2-5 минут при первом открытии)

6. Если появится уведомление "Gradle Sync" - дождитесь завершения

#### Настройка эмулятора

1. В верхней панели Android Studio найдите выпадающий список рядом с зеленой кнопкой ▶️

2. Если там написано "No Device" или "No Emulator":
   - Нажмите на этот список → **Device Manager**
   - Или через меню: **Tools** → **Device Manager**

3. В открывшемся окне Device Manager нажмите **Create Device** (кнопка с плюсом)

4. Выберите устройство:
   - Категория: **Phone**
   - Модель: **Pixel 3a** или любая другая (рекомендую со средними характеристиками)
   - Нажмите **Next**

5. Выберите образ системы:
   - Вкладка: **Recommended**
   - Выберите **R** (API Level 30) или **S** (API Level 31)
   - Если рядом есть кнопка **Download** - нажмите её и дождитесь загрузки
   - Нажмите **Next**

6. Проверьте настройки и нажмите **Finish**

7. Эмулятор появится в списке устройств

#### Запуск приложения

1. В верхней панели выберите созданный эмулятор из выпадающего списка

2. Нажмите зеленую кнопку **▶️ Run 'app'**

3. Первый запуск может занять 3-5 минут:
   - Gradle соберет проект
   - Запустится эмулятор (это медленно!)
   - Приложение установится на эмулятор

4. Когда эмулятор загрузится, вы увидите экран входа с надписью "Магазин крепежа"

## Проверка работы приложения

### Тестовый сценарий:

1. **Регистрация:**
   - Нажмите кнопку "Регистрация" (внизу экрана)
   - Введите логин: `test`
   - Введите пароль: `1234`
   - Нажмите "Зарегистрироваться"

2. **Вход:**
   - Введите те же логин и пароль
   - Нажмите "Войти"

3. **Каталог товаров:**
   - Должны увидеть список товаров с фотографиями:
     - Анкер 10x100 мм (45.50 ₽)
     - Болт М8x40 (12.30 ₽)
     - Саморез 4x16 мм (2.50 ₽)

4. **Добавление в корзину:**
   - Нажмите на любой товар
   - Нажмите кнопку "Добавить в корзину"
   - Повторите для других товаров

5. **Корзина:**
   - Нажмите на иконку корзины вверху (справа)
   - Увидите добавленные товары
   - Можете изменить количество кнопками + и -
   - Поставьте галочки у товаров, которые хотите оформить

6. **Оформление заказа:**
   - Нажмите кнопку "Оформить выбранное"
   - Должно появиться сообщение "Заказ успешно оформлен!"

## Частые проблемы и решения

### Сервер не запускается

**Проблема:** `ModuleNotFoundError: No module named 'flask'`
**Решение:** Повторите установку библиотек из Шага 2

**Проблема:** `could not connect to server: Connection refused`
**Решение:** PostgreSQL не запущен. Откройте "Службы" Windows (services.msc) и убедитесь, что служба "postgresql" работает

### Приложение пишет "Сервер недоступен"

**Проблема:** Сервер не запущен
**Решение:** Убедитесь, что в командной строке запущен `py app.py` и он работает (не закрыто окно)

**Проблема:** Неправильный адрес сервера
**Решение:** В коде используется `http://10.0.2.2:5000` - это специальный адрес для эмулятора. Если используете реальное устройство, нужно менять на IP компьютера в локальной сети.

### Android Studio долго собирает проект

Это нормально при первом запуске. Gradle скачивает все зависимости. Может занять 5-10 минут.

### Эмулятор тормозит

Включите аппаратное ускорение:
1. **Tools** → **SDK Manager** → **SDK Tools**
2. Установите **Intel x86 Emulator Accelerator (HAXM)**
3. Перезапустите компьютер
